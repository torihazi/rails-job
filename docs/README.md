# Rails Jobs Prototypes Docs

このディレクトリでは、各フェーズごとの学習タスクと参考情報をMarkdownで整理します。

## 構成方針

- `jobs-basic.md` など、ディレクトリ名に対応したファイルを作成してToDoやメモを記載する。
- 新規フェーズを追加する際は `_phase_template.md` をコピーし、ファイル名を対象ディレクトリに合わせる。
- 各ドキュメントは「目的」「学ぶべきこと」「実装タスク」「動作確認チェック」「参考リンク」「メモ」を共通セクションとして持つ。
- 追加リソースやメモはドキュメント末尾に追記し、更新日を明記する。

## 推奨テンプレート

- 主要な記入項目と説明が入った雛形は `_phase_template.md` に用意している。必要に応じてコピーして使用する。
- チェックボックス形式のタスクは進捗に応じて更新し、完了時はREADMEなどにも成果を反映する。

## 運用ルール

- 進捗管理はチェックボックスを用いて記録する。
- 新しいフェーズを追加するときは、テンプレートに従って新規ファイルを作成する。
- 更新時は冒頭に最終更新日を追記し、変更内容が分かるようにする。
- 共通的な知見は `docs/README.md` にも反映し、他フェーズで再利用できるようにする。
